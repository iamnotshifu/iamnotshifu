## 🚀 About Me

- 🧑🏾‍💻 Full-stack developer and founder building real products, not side projects that die in a repo.
- 🏢 Founder & CEO of [**NFORSHIFU234 Dev**](https://nforshifu234dev.com) — the studio behind an actual open-source ecosystem, not just a portfolio of one-off packages.
- 🎁 Building [**WishIT**](https://www.wish-it.app) — personalised digital wishes (WishDrops), shipped and iterating on real user feedback.
- 📦 As of **NFSFU234 Open Source Day (Aug 25, 2026)**, three libraries live under one scope: `@nfsfu234/shotsweep`, `@nfsfu234/tour-guide`, `@nfsfu234/form-validation`.
- 🧪 Every package here ships through a real CI/CD pipeline — trusted OIDC publishing, automated releases, no manual npm tokens.
- 🇳🇬 Lagos-built, built for people on 4G — that shapes every stack decision below.
- 🧬 The long version of how I got here lives on the [Evolution](https://www.iamnotshifu.com/evolution/portfolio) page.
- 📚 I write about the wins, the misses, and the "why" on [the blog](https://www.iamnotshifu.com/blog).
